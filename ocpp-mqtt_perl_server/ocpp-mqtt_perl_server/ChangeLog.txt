** 2025-12-03 Version 1.17
 - Added FALLBACK_BASELOAD general parameter to allow calculation of 
   Amperes/Watt for Wallbox Pulsar Plus.
 - Converted WAIT_CHANGE/WAIT_ON_START from samples to seconds.
   For values less than or equal to 20, it will be threated as samples and
   converted to seconds using 36 seconds per sample.
   If you need to use less than 20 seconds, add "s" at the end of the value.
 - Added configurable average "weight" based on seconds instead of samples.
 - Added configurable shell script command to execute when changing starts.
 - Removing "Available" from "STOP" status if connectorId=0 (seems a bug on
   ABB Terra AC).
 - Fixed recovering of sub-transaction in caso on server restart.
 - Recover status from server restart or broken connection.
 - Added the possibility to send an email when grid limit exceeded and not
   in CHARGE status.
 - Added MAX_ENERGY_SESSION parameter to stop charging when the limit is
   reached.
 - Added NO_AVERAGE parameter to increase/decrease current based on current
   power or on average power. The parameter is bit-mapped:
    0x01 = use instant (no average) power to increase
    0x02 = use instant (no average) power to decrease
    0x03 = use instant (no average) power both for increase and decrease
   The parameter could be useful to get energy only from solar-only power, 
   e.g. in summer to avoid too much power fetched from grid (NO_AVERAGE=2),
   or in winter to always retrieve all available excess of solar power 
   (NO_AVERAGE=1).
   When current reach the minimum (usually 6 A), average will be always
   used to suspend the session (0 A).
 - Fixed quick start back-counter handling, that could lead to very slow
   start.
 - Reducing select timeout and adding WAITDATA_TIMEOUT handling (Cmd and
   HandleQueue called every 10 seconds or if data is incoming).
 - Added the possibility to STOP the transaction for SUSPEND instead
   of limiting current profile to 0 A (seems some wallboxes do not
   like setting 0 A).
